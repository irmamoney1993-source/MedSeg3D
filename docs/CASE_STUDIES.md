# 典型病例分析

从固定验证集的 97 例中选择 TC 改善、退步、ET 误报及两模型性能接近的病例。表内为完整三维体积统计；展示图片为同空间位置的代表性切片。

| 病例 | TC Dice（U-Net → SegResNet） | 观察 |
|---|---:|---|
| BRATS_052 | 0.4879 → 0.9023 | 漏分体素 FN：30,626 → 6,274；FP：1,424 → 2,303。主要改善来自漏分减少。 |
| BRATS_184 | 0.3274 → 0.5057 | FN：7,523 → 3,651；FP：1,112 → 8,029。召回增加的同时误报明显增加。 |
| BRATS_024 | 0.6159 → 0.3620 | FP：3,693 → 10,303。SegResNet 预测区域扩大，TC Dice 下降。 |
| BRATS_023 | 0.6104 → 0.4515 | FP：3,431 → 10,848。漏分下降但误报增长更大。 |
| BRATS_413 | 0.8880 → 0.7324 | FP：722 → 3,283；额外误报影响 Dice。 |
| BRATS_339 | 0.9439 → 0.9438 | 两种网络的 TC 分割精度接近。 |

## ET 与小病灶

- **BRATS_036**：SegResNet 的 ET FP 由 3,538 增至 13,947；相关切片显示额外的误报区域。
- **BRATS_115**：真实 ET 仅 344 体素；SegResNet 虽降低 FN，但 FP 由 190 增至 699，ET Dice 下降。
- **BRATS_177**：真实 TC 仅 94 体素，SegResNet 的 TC FP 达 1,040，Dice 较低。
- **无真实 ET 的病例**：BRATS_024、023、177、175。U-Net 有 3 例产生 ET 假阳性，SegResNet 有 4 例；合计假阳性体素分别为 3,836 和 3,732。发生病例数与误报体积应分别报告。

图片坐标取自 RAS 重采样与前景裁剪后的三维数组，不能直接映射为原始 NIfTI 的体素索引。量化结论以体积级统计为准，选定切片不代表病例全貌。见 [结果图](../results/figures/) 与 [逐病例指标](../results/metrics/unet60_vs_segresnet60_per_case.csv)。
